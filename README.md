# Finora V3
نسخه بازطراحی‌شده وب‌اپ مدیریت سرمایه برای GitHub Pages.

- داشبورد فشرده و موبایل‌محور
- دارایی امن + سرمایه در گردش
- هدف دارایی امن
- بانک دارایی با دسته‌بندی و منبع قیمت
- معاملات و برنامه ورود
- تحلیل و نمودار بازه‌ای
- تابلو بازار
- Live price برای BTC و ETH از Binance public API
- Backup/Restore و LocalStorage
- بدون npm و بدون سرور؛ مناسب GitHub Pages

نکته: برای دلار، طلای ۱۸، بورس و نفت، APIهای عمومی/خصوصی بسته به منبع متفاوت‌اند. کلید خصوصی API نباید داخل GitHub Pages قرار گیرد؛ برای این منابع در نسخه بعدی می‌توان API Proxy امن اضافه کرد.
